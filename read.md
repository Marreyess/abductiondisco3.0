# Disco Abduction

Videojuego web desarrollado por Double M Studio para la materia Programación en Lenguajes Interpretados.

## Descripción

Disco Abduction es un videojuego 2D de aventura, exploración y ritmo musical en el que el protagonista debe recorrer una nave extraterrestre y superar enfrentamientos musicales para regresar a la Tierra.

## Tecnologías

- HTML5
- CSS
- JavaScript ES6
- Canvas
- Git y GitHub
